# MotionBridge — Fallen Doll 社区版 0.9.0b Mod v0.18.1

[English](README.md)

本包仅用于 **Fallen Doll 社区版 0.9.0b**（实测构建 7313），支持桌面及 VR 单人房，向 MotionBridge 提供动画骨骼数据。已包含配套 UE4SS 和社区版兼容修复。

## 安装

1. 关闭游戏，完整解压 ZIP。
2. 只运行一次 **Install Mod.cmd**。
3. 选择包含 Paralogue 的社区版游戏根目录。安装器自动核对可执行文件、备份已有安装文件、安装完整 Mod 并应用社区兼容修复。
4. 启动 MotionBridge 和游戏，进入实验室动画，确认 STREAM ONLINE；正常启动无需按 F10。

无需下载基础 Mod、另装兼容 ZIP 或选择 Playtest。安装会保留现有本地配置和 UE4SS 设置，仅更新 Mod 版本字段。

桌面及 VR 已实测双参与者数据流、冷启动及退出重进。社区版多人、其他可执行文件布局和真实设备动作尚未验证。不包含游戏文件、启动器和内容回移补丁。

0.18.1 是 Mod 版本；0.9.0b 是游戏版本；7313 是实测游戏的构建编号。Playtest 安装包独立维护。
