# MotionBridge — Fallen Doll 社区版 0.9.0b Mod v0.18.1

[English](README.md)

适用于 **Fallen Doll 社区版 0.9.0b**，支持桌面及 VR 单人房（实测构建 7313）。已包含 UE4SS，需配合 [MotionBridge](https://github.com/Huarch/MotionBridge/releases) 使用。

## 安装

1. 关闭游戏，完整解压 ZIP。
2. 运行 **Install Mod.cmd**，选择包含 `Paralogue` 的游戏根目录。
3. 启动 MotionBridge 和游戏，进入实验室动画，确认 **STREAM ONLINE**。

安装会保留现有本地配置和 UE4SS 设置。
