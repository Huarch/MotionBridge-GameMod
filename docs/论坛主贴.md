# 【MOD 分享】Operation Lovecraft: Fallen Doll 实时 TCode 支持

这是一个非官方社区 Mod，通过 UE4SS Lua 读取游戏当前帧的实时骨骼，并交给
F8Studio 生成 TCode。它不是按动画进度播放预制曲线，因此调整游戏动画速度后，
输出也会随画面动作同步。

当前版本：`0.15.0-l0-preview`

下载：[FallenDollTCode-0.15.0-l0-preview.zip](https://files.catbox.moe/d0co6p.zip)

SHA-256：
`9FBC601173F5213ECECD9A5D3B65E5E96BA2E15FB5FBAA6DF279519CA33AF175`

## 已实现

- 精确识别 HAnime，排除待机、表情和普通转场；
- 低负载采集 Hand、Foot、Mouth、Vaginal、Anal 等必要功能骨；
- 支持单人/多人参与者及功能骨优先级选择；
- F8Studio 3D 骨骼 Viewer、SR6/OSR Viewer 和 L0 信号链；
- 支持 USB 或 Wi-Fi TCode 输出，实体输出默认关闭；
- 离开动作、游戏退出或断流时自动进入安全状态；
- 支持 F10 热重载游戏侧 Lua Mod。

## 快速使用

1. 安装兼容的 RE-UE4SS。
2. 把发布包中的两个 Mod 复制到游戏的 `UE4SS/Mods` 目录并启用。
3. 使用包含 `Fallen Doll Source` 的 F8Studio，导入 v15 工程。
4. 启动 F8Studio 工程和游戏，进入 HAnime 后先打开 Viewer 检查动作。
5. 确认方向和范围正确后，只启用 USB 或 Wi-Fi 中的一种设备输出。

F8Studio 接入模块 PR：
[feel8-fun/f8studio#3](https://github.com/feel8-fun/f8studio/pull/3)

PR 合并前可使用 PR 分支或发布包内的 Source 补丁。详细步骤请查看包内《使用说明》。

## 当前限制

正式设备输出目前只使用 L0。部分左右手脚、双肢、特殊动作、多人和非人类姿势仍
需继续标注；L1/L2/R0/R1/R2 和 VR Viewer 将在后续版本中完善。

首次使用请保持实体输出关闭，只观察 Viewer。确认方向、范围、断流回中和紧急停止
方式后再连接设备。

本项目不包含游戏资源、UE4SS、F8Studio 本体或设备驱动。
