# 【MOD 分享】Fallen Doll 实时 TCode 支持（F8Studio / OSR2 / SR6）

这是一个为 Fallen Doll 制作的社区 TCode Mod，目前提供基于游戏实时骨骼的 L0
运动输出，可在 F8Studio 中预览，并连接 OSR2、SR6 等兼容 TCode 的设备。

本项目不修改或重新打包游戏 Pak，也不是根据动画进度播放预制曲线。Mod 会先精确
识别当前是否处于 HAnime，再读取画面当前帧的少量功能骨，因此调整游戏内动画速度
后，输出也会随实际动作同步变化。

> 当前为 `0.15.0-l0-preview` 测试版。请先使用 Viewer 检查动作，确认方向和安全范围
> 后再启用实体设备。

## 目前已经实现

- 使用 UE4SS Lua 采集游戏当前帧骨骼，支持 F10 安全热重载；
- 使用解包得到的 TableHAnim/Montage 白名单识别 HAnime；
- 排除待机、表情和普通转场动画，离开动作后停止有效输出；
- 自动识别单人及多人动作中的参与者；
- 按动作类别只采集 Hand、Foot、Mouth、Vaginal、Anal 等必要功能骨，避免高频全量
  枚举造成游戏卡顿或角色物理刷新；
- 游戏退出、离开 HAnime 或数据断流超过 250 ms 时进入安全状态；
- F8Studio 中提供 3D 骨骼 Viewer、SR6/OSR Viewer 和 L0 信号链；
- 可在 Fallen Doll Source 中启用或禁用参与者、左右手脚及其他功能骨；
- 支持 F8Studio 的 USB 或 Wi-Fi TCode 输出，两者不能同时启用；
- 已验证切换多个动作、调整动画速度、退出后重新进入，以及 USB/Wi-Fi 实机连接。

## 安装

1. 为 Fallen Doll 安装兼容的 RE-UE4SS。开发验证版本为：
   `3.0.1 Beta / d7e7826d415b0332b43439a64e6c87f64019be03`。
2. 解压发布包，把以下两个目录复制到游戏的 `UE4SS/Mods` 目录，并在 UE4SS Mod
   列表中启用：
   - `UE4SS-Mods/fd_tcode_probe`
   - `UE4SS-Mods/fd_tcode_reloader`
3. 使用包含 `Fallen Doll Source` 的 F8Studio，导入：
   `F8Studio/fallen-doll-skeleton-preview-v15.json`。
4. 先启动/部署 F8Studio 工程，再启动游戏并进入 HAnime。
5. 在 F8Studio 中打开 `FD 3D Skeleton Preview` 或 `FD SR6 OSR Viewer`，确认动作
   和 L0 信号正常。
6. 需要连接设备时，只启用一种输出：
   - Wi-Fi：在 `FD TCode Wi-Fi Out` 中填写设备地址和端口；
   - USB：在 `FD TCode USB Out` 中选择设备串口，默认波特率为 115200。

共享工程中的 USB 和 Wi-Fi 输出默认都处于关闭状态，USB 串口为空，不会在导入后
自动控制设备。

## F8Studio Source

Fallen Doll 的独立接入模块已提交到 F8Studio 上游：

[feel8-fun/f8studio#3](https://github.com/feel8-fun/f8studio/pull/3)

在 PR 合并进入官方版本之前，可以使用 PR 分支构建 F8Studio，或者向对应版本源码
应用发布包中的 `F8Studio/f8studio-fallen-doll-source.patch`。官方版本暂时没有
`Fallen Doll Source` 时，也可以继续使用项目旧版 v14 UDP Relay 方案。

## 游戏侧快捷键

- `F6`：开始或停止低频 HScene 诊断监视；
- `F8`：一次性导出当前运行时可见姿势列表，不是录制开关；
- `F10`：安全热重载 Fallen Doll Lua Mod。

正常使用不需要 F9。骨骼流会自动待命，由进入或离开 HAnime 控制有效输出。

## 当前限制

- 正式设备输出目前只使用 L0，其他五轴仍在开发；
- Hand/Foot 的左右侧、双肢同时参与和主次关系尚未覆盖全部姿势；
- 每条 HAnime 可能包含 1–2 条特殊动作，首版不会为其自动切换功能骨；
- 多人、非人类以及更多角色和姿势仍需要逐类验证；
- VR Viewer 尚未完成验证；
- v15 暂时依赖尚未合并的 F8Studio PR #3。

## 安全与反馈

首次使用请保持实体输出关闭，只观察 Viewer。启用设备前，请确认 L0 方向、范围、
断流回中和紧急停止方式。出现异常时应先关闭 F8Studio 输出节点，再退出游戏。

如果需要反馈问题，请尽量提供：

- 游戏版本、UE4SS 版本和 F8Studio 版本；
- 角色、HAnime 名称或能够复现的场景；
- 使用 USB 还是 Wi-Fi；
- Viewer 中的现象，以及是否只影响某一条动作；
- 删除隐私信息后的相关日志片段。

这是非官方社区项目，与游戏开发者、F8Studio 作者及设备厂商没有从属或背书关系。
