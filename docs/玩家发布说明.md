# Fallen Doll TCode Mod（L0 首发测试版）

## 简介

这是一个面向 Fallen Doll 的 UE4SS Lua + F8Studio 实时骨骼接入方案。Mod 只在
精确识别到游戏 HAnime 时采集当前参与者的少量功能骨，把实时姿态交给 F8Studio
计算 L0，并可用于 SR6/OSR2 的预览或 TCode 输出。

它不修改、不重打包 Pak，也不从动画进度条生成固定曲线。调整游戏动画速度后，
输出仍来自画面当前帧的骨骼相对位置。待机、退出动作、游戏关闭或数据中断超过
250 ms 时，安全链会回到中位。

当前版本以 L0 为正式目标。六轴、全部姿势标注和 VR Viewer 仍在后续计划中。

## 需要的文件

- `fd_tcode_probe/`：游戏侧实时骨骼 Mod。
- `fd_tcode_reloader/`：F10 安全热重载 Mod。
- `f8studio/fallen-doll-skeleton-preview-v15.json`：F8Studio 工程。
- 支持 `Fallen Doll Source` 的 F8Studio：上游 PR
  [feel8-fun/f8studio#3](https://github.com/feel8-fun/f8studio/pull/3)。
- PR 合并前的源码补丁：
  `f8studio/0001-feat-add-Fallen-Doll-skeleton-source-service.patch`。

发布包不包含游戏 Pak、解包资源、日志、缓存、串口号或其他玩家的设备设置。

## 安装与使用

1. 为 Fallen Doll 安装与当前游戏兼容的 UE4SS。开发验证版本为
   `3.0.1 Beta / d7e7826d415b0332b43439a64e6c87f64019be03`。
2. 把 `fd_tcode_probe` 和 `fd_tcode_reloader` 复制到游戏的 `UE4SS/Mods` 目录，
   并在 UE4SS 的 Mod 列表中启用两者。
3. 使用包含 `Fallen Doll Source` 的 F8Studio，导入
   `fallen-doll-skeleton-preview-v15.json`。
4. 启动或部署 F8Studio 图，再启动游戏并进入 HAnime。Source 默认自动读取：

   ```text
   %USERPROFILE%/.f8/studio/games/fallen-doll/runtime/fd-skeleton.ndjson
   ```

5. 在 F8Studio 中打开 `FD 3D Skeleton Preview` 或 `FD SR6 OSR Viewer` 检查动作。
6. 只有确认预览方向和幅度正确后，才手动启用一种实体输出：
   - Wi-Fi：在 `FD TCode Wi-Fi Out` 中配置设备主机和端口；
   - USB：在 `FD TCode USB Out` 中选择串口，波特率默认 115200。

Wi-Fi 与 USB 不应同时启用。共享工程中两个实体出口均默认关闭，USB 端口为空。

如果需要把所有游戏数据放到其他位置，可设置 `F8STUDIO_GAMES_DIR`；只修改
Fallen Doll 时可设置 `FD_TCODE_RUNTIME_DIR`。游戏 Mod 与 Source 必须看到相同
的环境变量。

## 游戏侧快捷键

- `F6`：开始/停止低频 HScene 诊断监视。
- `F8`：一次性导出当前运行时可见姿势列表，不启动录制。
- `F10`：通过独立 broker 热重载 Lua Mod。

骨骼流随 Mod 自动待命，不需要 F9。离开 HAnime 后会自动停止输出，再次进入时
自动恢复。

## 已完成

- 使用解包的 TableHAnim/Montage 白名单排除待机、表情和普通过渡动画；
- 识别单人及多人 HAnime 的功能参与者，并保留角色目录和优先级；
- 以 20 Hz 目标频率采集紧凑功能骨，不逐帧全局枚举，不再造成角色物理刷新；
- F8Studio 独立 Source 自动读取文件，不要求玩家单独启动 Relay；
- 参与者和左右手/脚/口/Vaginal/Anal 等功能骨可按优先级选择或禁用；
- 3D 骨骼 Viewer、SR6 OSR Viewer、L0 平滑、防跳、限速和断流回中；
- USB 与 Wi-Fi TCode 通路，且实体输出默认关闭；
- 已验证切换多个动作、改变动画速度、退出后重新进入和 USB/Wi-Fi 实机连接。

## 当前限制

- 正式实体输出目前只使用 L0；
- Hand/Foot 的左右侧、双肢同时参与和主次关系尚未覆盖全部姿势；
- 每条 HAnime 可能存在 1–2 条 special 动作，首版不自动切换功能骨；
- 非人类、更多多人组合和全部角色仍需逐类验证；
- F8Studio PR 合并前，官方版本可能还看不到 `Fallen Doll Source`；此时可继续
  使用旧 v14 UDP Relay 工程，或使用 PR 分支。

## 安全说明

初次测试请保持实体设备关闭，只观察 Viewer。启用设备前应确认 L0 方向、范围、
断流回中和紧急停止方式。任何异常都应先关闭 F8Studio 的输出节点，再退出游戏。
