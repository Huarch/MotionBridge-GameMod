# Operation Lovecraft: Fallen Doll TCode Mod

版本：`0.15.0-l0-preview`

本测试版使用 UE4SS Lua 读取实时 HAnime 骨骼，并通过 F8Studio 输出 L0。它会排除
待机和普通转场；离开动作、游戏关闭或断流时会进入安全状态。

## 安装

1. 关闭游戏，把包内 `Game` 目录中的全部内容复制到：
   `Operation Lovecraft Fallen Doll Playtest/Paralogue/Binaries/Win64`。
   发布包已经包含已验证的 UE4SS，无需另行安装。
2. 使用包含 `Fallen Doll Source` 的 F8Studio，导入
   `F8Studio/fallen-doll-skeleton-preview-v15.json`。
3. 先启动 F8Studio 工程，再启动游戏并进入 HAnime。
4. 打开 3D Skeleton Viewer 或 SR6/OSR Viewer 检查动作。
5. 确认方向与范围正确后，只启用 USB 或 Wi-Fi 中的一种输出。

USB 和 Wi-Fi 默认关闭，USB 端口为空。首次使用请先只观察 Viewer。

## 快捷键

- `F6`：开始/停止低频诊断；
- `F8`：一次性导出当前姿势列表；
- `F10`：安全热重载 Lua Mod。

## 限制

当前正式设备输出仅使用 L0。部分左右手脚、双肢、特殊动作、多人及非人类姿势仍
需继续标注；其他五轴和 VR Viewer 将在后续版本中完善。
