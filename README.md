# MotionBridge — Fallen Doll Community 0.9.0b Mod v0.18.1

[简体中文](README-ZH.md)

This package is exclusively for **Fallen Doll Community 0.9.0b** (tested build 7313), Desktop and VR single-player rooms. It streams animation bone data to MotionBridge. The matching UE4SS runtime and community fixes are included.

## Install

1. Close the game and extract the entire ZIP.
2. Run **Install Mod.cmd** once.
3. Select the community game root containing Paralogue. The installer validates the executable, backs up existing package files, installs the complete Mod and applies community compatibility automatically.
4. Start MotionBridge and the game, then enter a laboratory animation. Confirm STREAM ONLINE. Normal startup does not require F10.

No base Mod download, additional compatibility ZIP or edition choice is needed. Existing local configuration and UE4SS settings are preserved; the Mod version field is updated.

Desktop and VR two-participant streams, cold startup and exit/reentry were verified. Community multiplayer, other executable layouts and physical-device movement remain unverified. Game files, launchers and content backports are not included.

Version 0.18.1 identifies the Mod; 0.9.0b is the game version. Build 7313 identifies the tested executable. Playtest packages are maintained separately.
