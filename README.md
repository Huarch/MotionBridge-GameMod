# MotionBridge — Fallen Doll Community 0.9.0b Mod v0.18.1

[简体中文](README-ZH.md)

For **Fallen Doll Community 0.9.0b**, Desktop and VR single-player rooms (tested build 7313). UE4SS included. Requires [MotionBridge](https://github.com/Huarch/MotionBridge/releases).

## Install

1. Close the game and extract the entire ZIP.
2. Run **Install Mod.cmd** and select the game root containing `Paralogue`.
3. Start MotionBridge and the game. Enter a laboratory animation and confirm **STREAM ONLINE**.

Existing local configuration and UE4SS settings are preserved.
