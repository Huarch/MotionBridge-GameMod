# MotionBridge Game Mods

This repository keeps game-specific MotionBridge Mod integrations on separate branches.

| Branch | Game / edition | Purpose |
| --- | --- | --- |
| `fallen-doll-demo` | Fallen Doll Demo | Stable Demo integration |
| `fallen-doll-playtest` | Fallen Doll Playtest | Active Playtest integration |

`master` intentionally contains only this repository guide. Check out the branch that matches the game and edition you are using.

## 中文说明

本仓库按游戏 Mod 分支维护。请根据使用的游戏和版本切换到对应分支：

- `fallen-doll-demo`：Fallen Doll Demo 稳定版
- `fallen-doll-playtest`：Fallen Doll Playtest 持续更新版

`master` 仅保留仓库说明，不包含 Mod 程序文件。
